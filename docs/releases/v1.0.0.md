# 拾日 v1.0.0 · 纪念日与照片

拾日首次源码发布：在本机记录重要日期，整理每一年的照片。支持 iOS 16+、Android 8+ 和原生桌面小组件。

## 新功能 / New Features

1. **纪念日与提醒**：累计天数、周年倒计时、年度或单次事项，可按需写入本机系统日历。
   **Anniversaries and reminders**: track elapsed days and upcoming dates, with annual or one-time local calendar reminders.
2. **相册与封面**：新建后尝试一次照片归集，后续手动触发，支持按年份浏览、多选管理和多种封面播放方式。
   **Albums and covers**: collect photos once after creation, refresh explicitly, browse by year and manage selections and cover playback.
3. **备份与互传**：导出完整原图备份，预览合并导入，双方确认配对码后通过局域网加密互传。
   **Backup and transfer**: export full-resolution archives, preview merges and transfer over a local network after confirming the pairing code.
4. **原生桌面小组件**：iOS WidgetKit 与 Android App Widget 展示用户封面及纪念日天数。
   **Native widgets**: show personal covers and anniversary counts on iOS and Android home screens.

## 下载 / Downloads

- `shiri-debug.apk`：Android 开发签名调试包，非商店发行包。Android development-signed debug build.
- `shiri-ios-unsigned.zip`：iOS 未签名应用，不能直接安装到 iPhone；需要自己的开发团队与 App Group 签名。Unsigned iOS app; developer signing is required for device installation.
- `SHA256SUMS`：以上附件的 SHA256 校验摘要。Checksums for both packages.
- `v1.0.0-manifest.json`：版本、工具链、附件摘要与历史构建记录。Build metadata and artifact digests.

下载到同一目录后运行 `shasum -a 256 -c SHA256SUMS` 校验。

## 验证与限制 / Validation and Limitations

2026-11-17：Flutter 静态检查通过，75 项测试全部通过。附件复用现有开发验收构建，本轮已复核文件大小、SHA256 及 Dart 源码摘要，未重新编译原生包。

Static analysis and all 75 Flutter tests passed. Existing development artifacts were reused after checking package sizes, SHA256 digests and the Dart source digest; native packages were not rebuilt in this publication task.

双真机 BLE/LAN 互传、长时间传输、网络切换及 iOS 真机小组件仍需验收。小组件刷新受系统调度限制。`.shiri` 备份包含原图且未使用密码加密，请妥善保存。

Two-phone BLE/LAN transfers, long transfers, network changes and signed-device iOS widgets still require acceptance testing. Widget refresh follows system scheduling. Exported `.shiri` archives contain original photos and are not password-encrypted.
